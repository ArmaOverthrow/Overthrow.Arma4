**Found by:** dev-ops/test-coverage Phase 1 spike (findings.md bug #1). Deterministic, reproduced identically in two independent runs (62 exceptions each), ~6.5 s after campaign start when `DistributeInitialResources` spends the occupying faction's starting resources.

**Stack:** `SCR_InventoryStorageManagerComponent.OnItemAdded` (NULL pointer to instance) ← `OVT_BaseUpgradeComposition.c:73 FillAmmoboxes` ← `:43 Spend` ← `OVT_BaseControllerComponent.c:299 SpendResources` ← `OVT_OccupyingFactionManager.c:500 DistributeInitialResources`.

**Impact:** floods `console.log` with 62 script errors on every campaign start. Blocks feature #4 (ci-pipeline) from ever using console error counts as a CI signal. Likely ammoboxes never actually fill at affected bases.
