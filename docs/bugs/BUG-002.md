**Found by:** dev-ops/test-coverage Phase 1 (findings.md bug #2 — rated highest-severity in the list). Two compounding halves:

1. `OVT_PersistenceManagerComponent.SaveGame()`/`AutoSave()` fail **completely silently** on the current branch — `m_PersistenceSystem` is null, so even the guarded `TODO(vanilla-persistence)` warning never prints. The caller gets no failure indication whatsoever.
2. `OVT_MainMenuContext.c:262-271` shows `#OVT-Saved` **unconditionally** after requesting a save.

**Net effect:** a player pressing Save today is told the game saved, and nothing anywhere records that it did not. Even after the migration restores a real save path, the UI half remains wrong — success feedback should be driven by the actual save outcome.
