**Found by:** dev-ops/test-coverage Phase 4 (findings.md bug #10, found by source reading while choosing test seams).

`OVT_OwnerManagerComponent.DoSetOwnerPersistentId()` overwrites `m_mOwners[pos]` but only *inserts* into the new owner's `m_mOwned` list — it never removes the position from the old owner's list. After a transfer: `GetOwnerID(building)` reports the new owner, `IsOwner(oldOwner, id)` still returns **true**, and `IsOwned()` scans the stale list.

**Impact:** real-estate data integrity — any transfer/sale path leaves both players "owning" the building by one accessor while only one owns it by the other. The persistence test suite deliberately routes around this by only taking unowned buildings (`GetRandomUnownedHouse()`); fix will need a test update to cover transfers properly.
