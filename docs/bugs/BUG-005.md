**Found by:** dev-ops/test-coverage Phase 5 (findings.md bug #11). Pinned by test `OVT_TEST_Logic_Jobs_DealerCondition_PinsAxisOnlyCheckBug`, which asserts the current behaviour and will go red when this is fixed (update the test deliberately when fixing).

The condition is `if (town.gunDealerPosition && town.gunDealerPosition[0] != 0)` — a gun dealer standing anywhere on the X = 0 plane reads as "no dealer" regardless of Y/Z. Evident intent is "is the position set", which the X-only check doesn't express (a proper zero-vector check would). Harmless on Everon and the test world; bites any map with a town near the western world edge.
