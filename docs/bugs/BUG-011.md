**Found by:** dev-ops/test-coverage Phase 1 (findings.md bug #7 — recorded as a content trap).

`OVT_Campaign_Test_Layers/default.layer`'s `m_aDifficultyPresets` override appends to the prefab's list rather than replacing it: 5 presets exist at runtime and **'Test World' is index 4, not 0** (index 0 is 'Easy': cash 500 vs Test World's 100000). Anything selecting the test-world difficulty by index silently runs on Easy. The test suite base now selects by `preset.name == "Test World"` to dodge this; worth deciding whether the layer should truly replace the array (or the trap should be documented on the world asset).
