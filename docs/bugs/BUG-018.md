**Found:** 2026-08-03 SP playtest of the vanilla-persistence migration (checklist item 12c). Items 1–15 otherwise green.

**Expected:** Killed characters (enemies, recruits) remain in the world as lootable corpses after save → quit → Continue, still carrying their weapons/inventory. Implemented in Phase 4 via `OVT_DeadCharacterPersistenceConfigRule` + a standalone `EntityPersistenceConfig` in `Configs/Systems/Persistence/Overthrow.conf` (`Priority 36000`, `SelfSpawn 1`, Character collection, vanilla's six character serializers) and a death-time re-match (`OVT_OverthrowGameMode` subscribes `m_OnCharacterKilled` → `OVT_PersistenceTracking.ReloadConfig(victim)`, twice: immediately + one frame later).

**Observed:** Corpses are gone after a continue.

**Prime suspects (the design's documented benign failure mode is exactly this symptom):**
1. The standalone config was chosen over inheriting `Character.conf` precisely so that a silent failure means "rule does not match → corpses simply do not come back" (see context.md, Phase 4 corpse note). So the rule most likely never matches: check `OVT_DeadCharacterPersistenceConfigRule.IsMatch` is actually reached (is the config's rule GUID wired right in `Overthrow.conf`? does `ReloadConfig` re-evaluate rules the way we assumed?).
2. Timing: `IsDead()` may still be false at BOTH re-match attempts (immediate + 1 frame) if the controller's life state lags the damage manager's kill event by more than a frame.
3. The corpse may re-match but keep/get the AI config (`SelfSpawn 0`, Priority?) if 36000 does not actually beat the matched config at reload time.
4. `SelfDelete` semantics: if the engine drops a tracked instance's record when the body despawns/cleans up before the save, there is nothing to restore.

**Repro:** Kill an armed enemy, do NOT loot, save, quit, Continue → body absent.

**Notes:** User assessment: minor — EPF did not persist corpses either (this was a new capability, not a regression). Not blocking the playtest or the merge. Automated coverage gap: the round-trip suite has no corpse case; when fixing, add one and prove it can fail.
