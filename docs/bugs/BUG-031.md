**Found by:** occupying epic discovery (`/discover-feature occupying/qrf`, 2026-08-02).

Two defects in `OVT_QRFControllerComponent`'s landing-zone selection neutralize its wave-spread and terrain-safety design:

1. **The clear-box trace is a no-op** (`:487-494`): `float result = TracePosition(trace, null); if (result >= 0)` — `TracePosition` returns a 0..1 fraction where 1.0 means "no hit", so `>= 0` is **always true**. The nominal "check for a clear 10×10×10 landing zone" accepts every candidate; QRF groups can and do spawn inside geometry.
2. **File-scope mutable globals cache the first LZ** (`:4-5`): `Goodqrfpos` / `Goodqrfbasepos` are globals, not instance fields. `GetLandingZone()` returns the cached `Goodqrfpos` immediately on every call after the first (`:453`), so **every source base in `SendWave`'s per-base loop uses the identical landing zone** — the per-base loop, direction randomization (`m_iPreferredDirection` ± variance) and the 450-attempt search all collapse to one spawn point per battle. The globals are reset only in `SendTroops` (`:227-228`), i.e. once per QRF, and being file-scope they leak across any future controller instances.

Adjacent issues in the same path (fix opportunistically): the preferred-direction wrap logic (`:397-408`) produces inverted min/max ranges near 0°/360°; `OVT_Global.IsOceanAtPosition` (`OVT_Global.c:421-422`) uses a hardcoded 1 m sea level with an unreachable second return; and `GetRandomDirection` contains two unguarded `Print`s inside the 450-attempt loop (~900 log lines per LZ resolution).

Fix shape: compare the trace fraction against 1.0 (or use the hit flag) for the clear check; make `Goodqrfpos`/`Goodqrfbasepos` instance fields reset per wave (or remove the cache — the design clearly intended one LZ *per source base*); normalize the direction range before sampling. The direction/wrap math is a world-free Logic-tier test candidate.

**Impact:** every QRF arrives as a single clump from one direction (per-base attack-geometry authoring in `bases.layer` is largely cosmetic), sometimes embedded in buildings/terrain — visibly broken battles and trivially predictable defense.
