**Found by:** towns epic discovery (`/discover-feature towns/gun-dealers`, 2026-08-02).

`OVT_TownController.SpawnGunDealer` (`OVT_TownController.c:305`): `int index = s_AIRandomGenerator.RandInt(0, entries.Count()-1);` — `RandInt(min, max)` is half-open (max exclusive), so the last entry of the candidate list can never be picked for any `m_bSingleRandomItem` rule. Those rules are the "one random weapon per category per town" travel mechanic (generic weapon, rocket launcher, sniper rifle, machine gun). The same idiom repeats in `InitShopInventory` (`OVT_EconomyManagerComponent.c`).

**Impact:** one specific weapon per heavy category is unobtainable from any gun dealer, forever. Which weapon depends on catalog build order (itself order-dependent — see the economy market docs on the int resource-ID system), so DLC/mod additions silently change which item is excluded.

**Fix shape:** `RandInt(0, entries.Count())` at both sites (verify against the engine's `RandInt` contract first — the codebase mixes conventions; the weed roll at `:284` uses `RandInt(min, max)` as if inclusive).

**Test note:** a Logic-tier candidate — the pick loop is pure given a stubbed entry list, but `s_AIRandomGenerator` has no seam; a distribution-over-many-rolls case would need one.
