**Found by:** towns epic discovery (`/discover-feature towns/gun-dealers`, 2026-08-02).

`OVT_EconomyManagerComponent.ReplenishStock` (`:314-328`) iterates only `m_GunDealerConfig.m_aGunDealerItemPrefabs` — shipped content: weed. The entire `m_aGunDealerItems` catalog (every gun, all ammunition, attachments, throwables, explosives) has no restock path, and the dealer is deliberately excluded from the town shop registry (`FilterShopEntities:1535`), so the shared town restock pass can't reach it either. The comment at `:314` ("Item prefabs only ie weed") shows a conscious scope limit — but the localized `findGunDealer` job description promises the dealer "will sell all ammunition".

**Impact:** on a long single-session campaign, a bought-out dealer never sells that weapon/ammo again. The only recovery is a save/load: `SpawnGunDealer` reuses the persisted position but re-rolls all stock (`OVT_TownController.c:282-333`) — an undocumented full inventory refresh that also re-randomises the per-town heavy weapons.

**Fix shape:** extend `ReplenishStock`'s dealer branch to re-run (or top up from) the catalog rules on the same economic-clock cadence — or embrace scarcity deliberately and fix the job text.
