**Found during:** economy QOL sweep for the shop-ux feature (2026-08-04).

`OVT_WarehouseContext.OnShow()` (`Scripts/Game/UI/Context/OVT_WarehouseContext.c:14-24`) wires all three take buttons via a copy-paste error — the `Take10Button` and `Take100Button` blocks both call `take1.FindHandler(...)` instead of using their own widgets:

```
Widget take10 = m_wRoot.FindAnyWidget("Take10Button");
action = SCR_InputButtonComponent.Cast(take1.FindHandler(SCR_InputButtonComponent));  // <-- take1
action.m_OnActivated.Insert(TakeTen);
```

**Effect:** `TakeOne`, `TakeTen` and `TakeHundred` are all inserted on the *Take 1* button's component. Clicking "Take 1" fires all three and requests 1+10+100 = 111 items (capped at available stock), while the "Take 10" and "Take 100" buttons do nothing at all.

**Fix shape:** use `take10.FindHandler(...)` and `take100.FindHandler(...)` respectively. Fold into the shop-ux PR's warehouse QOL pass.
