## Summary

`OverthrowMainMenu` is bound to `gamepad0:pad_down` and lives in `OverthrowGeneralContext`, which is **active every frame**. Every Overthrow menu context that lists `MenuDown` — which is every one of them, because d-pad-down navigation is mandatory for gamepad usability — therefore collides with it.

This single binding is the root of **17 of the 23 warnings** and **2 of the 12 BASE entries** reported by `check-input-conflicts.py`. It is described by the Phase 6 implementer as *"the single highest-value input fix available in the mod."*

## Expected

D-pad down moves menu focus down, and nothing else.

## Actual

D-pad down simultaneously moves focus and fires the always-live open-main-menu action.

## Why this is not fixable by editing the report

Removing `OverthrowMainMenu` from `OverthrowMainMenuContext`'s `ActionRefs` would silence most of the warnings **without changing behaviour**, because `OverthrowGeneralContext` fires the action every frame regardless. That would be a stale waiver — the report would look clean while the collision persisted. It was deliberately left in place rather than papered over.

## Suggested fix

Rebind the mod's primary open-menu pad input to something not used for menu navigation. This is an **owner-level input-scheme decision**, not a mechanical edit — it changes muscle memory for every existing player, so it wants a deliberate choice about the replacement rather than a first-free-button pick.

Once rebound, the warning count should drop from 23 to roughly 6, and the baseline in `docs/features/new-player-experience/tutorial-system/context.md` should be re-recorded.

## Impact on the current gate

The tutorial-system feature's Phase 6 added a 17th menu context and the warning count went **22 → 23** — one more instance of this same collision. That was accepted as structural: a new menu context that lists `MenuDown` (required for gamepad navigation) *cannot* land at 22 while this binding exists. Errors stayed at 0 and BASE stayed at 12.

## How it was found

Found while implementing `new-player-experience/tutorial-system` Phase 6, investigating why a correctly-built 17th menu context could not meet a "no new warnings" gate.
