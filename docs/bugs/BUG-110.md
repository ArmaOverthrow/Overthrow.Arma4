## How this was found

Source verification during `new-player-experience/field-manual` authoring. The manual needed a rule for what makes a player wanted; the sweep read every escalation site and found that the two violence paths are the only ones that are not seen-gated, and the only ones that do not care who the victim is. Documented as it ships ("violence needs no witness"), because that is the behaviour, with the question raised rather than answered.

## Symptom

Two behaviours, of which the second is the more likely defect:

1. **No witness required.** Wounding anybody sets wanted level 2 and killing anybody sets wanted level 3, whether or not a single occupying-faction soldier or civilian saw it. Every other escalation path in `OVT_PlayerWantedComponent` consults `m_bIsSeen` / `m_bTempSeen`.
2. **No faction check.** The victim's faction is never examined. Shooting a **civilian**, or **your own recruit**, or **another resistance player**, alone in an empty field, makes you wanted exactly as fast and exactly as far as shooting an occupying-faction soldier in a town square.

## Root cause

`Scripts/Game/Components/Damage/Modded/SCR_CharacterDamageManagerComponent.c`.

**Any damage, to anyone, level 2** (`:15-40`):

```c
void WhenDamaged(BaseDamageContext damageContext)
{
    if(damageContext.instigator)
    {
        IEntity entity = damageContext.instigator.GetInstigatorEntity();
        if(entity)
        {
            OVT_PlayerWantedComponent wanted = OVT_PlayerWantedComponent.Cast(entity.FindComponent(OVT_PlayerWantedComponent));
            if(wanted)
            {
                if(wanted.IsDisguisedAsOccupying()) { wanted.SetBaseWantedLevel(2, "WantedDisguiseBlown"); wanted.BlowDisguise(); }
                else                                { wanted.SetBaseWantedLevel(2); }
            }
        }
    }
}
```

The only conditions are "there is an instigator" and "the instigator is a player". `GetOwner()` (the victim) is never inspected, and neither `m_bIsSeen` nor `m_bTempSeen` is read.

**Any kill, of anyone, level 3** (`:44-82`):

```c
if(instigator)
{
    OVT_PlayerWantedComponent wanted = OVT_PlayerWantedComponent.Cast(instigator.FindComponent(OVT_PlayerWantedComponent));
    if(wanted)
    {
        if(wanted.IsDisguisedAsOccupying()) { wanted.SetBaseWantedLevel(3, "WantedDisguiseBlown"); wanted.BlowDisguise(); }
        else                                { wanted.SetBaseWantedLevel(3); }
    }
}
```

Note that this block sits **outside** the `if(IsOccupyingFaction())` guard at `:55-61`. The faction check exists in the same function, a few lines above, and is used for the `OnAIKilled` scoring call and the vehicle sweep, but not for the escalation. That is the clearest signal that the missing faction check on the escalation is an oversight rather than a decision: the very information needed is already computed and cached (`IsOccupyingFaction`, `:84-98`, memoised in `m_bIsOccupyingFaction`).

**By contrast, every other escalation is seen-gated.** `OVT_PlayerWantedComponent`'s proximity and visibility paths (`:528`, `:538`, `:566`, `:779`) all run inside the seen/search logic, and the level-1 decay tail at `:560` explicitly requires `m_bTempSeen` to re-escalate.

## Fix (proposed)

**Split the two halves; they deserve different verdicts.**

**The missing faction check is the likely defect.** Reuse the value the same class already has:

```c
// in WhenDamageStateChanged, move the escalation inside the existing guard
if(IsOccupyingFaction())
{
    OVT_Global.GetOccupyingFaction().OnAIKilled(GetOwner(), instigator);
    GetGame().GetWorld().QueryEntitiesBySphere(...);
    // ... escalate the instigator here
}
```

and add the equivalent check to `WhenDamaged`. What should happen when the victim is a **civilian** is a separate gameplay decision (harming civilians plausibly *should* carry a penalty, but arguably a support/stability penalty rather than a military wanted level, and arguably not the same level as attacking a soldier). What should happen when the victim is **your own recruit or another resistance player** is much clearer: it should almost certainly not make you wanted at all.

**"Violence needs no witness" may well be intended** and is not asserted here as a bug. It is a coherent rule (the occupying faction notices its own casualties without needing an eyewitness) and it is what both help surfaces now describe. It only becomes odd in combination with the missing faction check, where an unwitnessed act against a non-occupying victim escalates you. Fixing the faction check may make the witness question moot.

No code change should be made here until a gameplay owner rules on both halves.

## Audit 2026-09-03

Half fixed by commit 3becfbeb (v1.5.0 "Crashing your car would make you wanted"). `SCR_CharacterDamageManagerComponent.c:21` and `:71` now skip self-inflicted damage and any victim of the player faction. The test `OVT_TEST_Init_Wanted_OnlySomebodyElsesSideIsACrime` covers the friendly case. Still open: a civilian victim escalates, and there is no witness check. A design ruling on civilians is owed before a fix.
