## Symptom (observed on gamepad, 2026-08-13)

Opening the main Overthrow menu requires holding **LT** and pressing **d-pad Down** — and holding LT zooms (or aims, weapon raised), so every menu open zooms the camera first.

## Mechanism

`Action OverthrowMainMenu` binds an `InputSourceCombo` of `gamepad0:left_trigger` + `gamepad0:pad_down`. On the vanilla side LT is **`FocusAnalog`** — an **unfiltered analog axis** inline in `PlayerCameraContext` (Priority 40, active whenever the camera handler runs) — plus `CharacterWeaponADS`/`ADSHold` (`CharacterWeaponContext`, Priority 10) with a weapon out, and `FocusToggleUnarmed` (Priority 40). An analog axis fires the moment the trigger moves, so **no combo timing can win**: the zoom is engaged before the combo resolves, and shadowing LT from an Overthrow context would kill zoom/ADS everywhere that context is active (`OverthrowGeneralContext` is effectively always on). LT-as-modifier is structurally unfixable, not mistuned.

## Fix shape — rebind the pad chord, keep KC_U

Replace the combo's modifier half. Ranked options:

1. **`shoulder_right` (RB) + `pad_down`** — recommended. RB is unbound in the character tier (verified against the vanilla action pool), and RB+d-pad combos are vanilla's own editor idiom (`EditorContext` uses `shoulder_right`+`pad_up`/`pad_down`/`pad_right`). The repo's UI skill likewise lists `shoulder_right` among the safe menu inputs. One conf edit inside the existing `InputSourceCombo`.
2. **Hold `pad_down` alone (`InputFilterHold`)** — no modifier at all, but collides with vanilla's gadget quick-slots on pad_down: `GadgetBinoculars` is itself a **HoldOnce** there and `GadgetCompass` a double-click. Rejected unless (1) fails in testing.
3. Accept the zoom — the fallback if RB turns out to matter in some vehicle/turret context (RB was only verified free in the character tier).

⚠️ Whatever chord is chosen, re-run `check-input-conflicts.py` **and** reason by hand about the base game's ~197 inline context actions — the checker cannot see them (the BUG-154 lesson), and this combo's members must be checked in every context the player can be in when the menu is legal.

## Provenance

Reported by the user after gamepad play-testing, 2026-08-13. The user's own read — "it could also be the only option we had" — is half right: LT is unusable as a modifier, but the modifier itself is replaceable.
