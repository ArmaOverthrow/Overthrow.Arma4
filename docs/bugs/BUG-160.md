## Symptom (observed on gamepad, 2026-08-13)

Walking the place menu's item grid with the d-pad, the "currently highlighted" indication on the focused card is a very thin band — easy to lose entirely against the card art. On a pad this is the selection cursor, so losing it means not knowing what A will place.

## Mechanism

`UI/Layouts/Menu/PlaceMenu/PlaceMenu_Card.layout` draws the focus/hover indication as a `Border` widget in the accent colour with **`style outline_2px`** (plus `m_bShowBorderOnHover 1` on the card component). A 2px outline reads fine for a mouse hover that follows the pointer, but as a persistent gamepad focus cursor it is below the visibility floor.

## Fix shape

Strengthen the focused state on the card layout — candidates, combinable: a thicker outline; a translucent accent-colour fill overlay behind the card content (the pattern the shop menu's selected state uses is the house reference — check `ShopMenu_Card` before inventing one); or a slight focused-scale/brightness step. Keep hover (mouse) and focus (pad) visually identical so the two input models don't diverge. Layout-only change; invisible to every automated gate, so the acceptance check is a human in Workbench walking the grid on a pad.
