## Symptom

On dedicated servers, only one FOB and one camp marker appear on the map regardless of how many exist. Additionally, camp markers appeared on map open and vanished at the first touch of the zoom.

## Root cause

Two halves:

1. `OVT_MapLocationData.m_RplID` was default-constructed. A default `RplId` is 0, and 0 answers `IsValid()` true — so every record that never set one aliased to the same id, and the refresh reconciliation collapsed all FOB and camp markers to one apiece. Fix: initialise to `RplId.Invalid()` (`OVT_MapLocationData.c`).
2. A newly created marker element skipped the four visibility gates every existing marker has already passed, so it was born fully visible regardless of zoom/filter and only snapped to the right state on the NEXT zoom/filter event. Fix: `RefreshVisibility()` on creation (`OVT_OverthrowMapUI.c`).
