> ID note: fixed on main 2026-08-20 (commit 2e0ce7df), where the session numbered it BUG-187 locally; filed as BUG-191 at merge time — v1.5/tracker BUG-187 is the NULL-UUID identity bug.

## Symptom

When a player disconnects, their parked recruits' bodies remain visible to every client — frozen, unkillable ghosts — even though player bodies and locked vehicles now disappear correctly (BUG-185's fix).

## Root cause

Reserved recruit bodies go through the same `OVT_PersistenceReservation.Reserve()` path as player bodies, but `Prefabs/Characters/Factions/CIV/Character_CIV_Recruit.et` was the one reservable prefab BUG-185's `OVT_ReservationSyncComponent` wiring missed — so recruits kept the old authority-only (server-local flags) behaviour.

## Fix

`OVT_ReservationSyncComponent` added to `Character_CIV_Recruit.et`.

## Test

`OVT_TEST_Init_Persistence_ReservationReplicatesToClients` grew a recruit-half wiring tripwire, reached through the recruit manager's own prefab attribute so a re-pointed prefab is checked wherever it points.
