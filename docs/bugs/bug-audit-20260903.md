## 2. Play-tests

All three passed on 2026-09-03 and the records are closed. The steps stay here as the repro record.

### BUG-193: built bunker has no live RplComponent

The fix is in `E_Sandbag_01_bunker_plastic_foundation_camonet.et:72-74` (commit 00949009, in v1.5.0). No test covers it. Dedicated server with one client:

1. Build a Bunker at an FOB from the client.
2. Disconnect the client and rejoin. Make sure the bunker is visible.
3. Run Dismantle on the bunker from the client. Make sure the bunker disappears for the server and the client.

### BUG-154: map info panel close button on gamepad

Not fixed. The audit changed the cause: both the vanilla `MapEscape` and `OverthrowCloseInfoPanel` fire on B, and the map closes first. The record was filed from a config read and never reproduced. SP with a gamepad:

1. Open the map and pin an info panel on a marker.
2. Press B. Record whether the panel closes or the map closes.

### BUG-171: new recruits run to the formation anchor

Not fixed. No follow or move order exists after `AddAIToSlaveGroup` (`OVT_RecruitManagerComponent.c:2406`). The record was filed from a code read. SP:

1. Send every active recruit 100 m away from a recruitment tent, or set them inactive.
2. Hire one recruit at the tent. Record whether the recruit stays at the tent or runs to the other recruits.
