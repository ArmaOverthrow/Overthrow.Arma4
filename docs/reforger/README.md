# Arma Reforger Version-Change Reports

Reports on what changed between Arma Reforger builds and how it affects Overthrow.
Generated by the `/update-reforger` slash command (see `.claude/commands/update-reforger.md`).

## How it works

1. `update-arma-scripts.ps1` (repo root) extracts the installed game's paks into the
   reference tree at `N:\Projects\Arma 4\ArmaReforger`, stamping it with a
   `.version.json` marker (`{buildId, label, extracted}`). When a **new** game build
   replaces an older tree, the old tree is archived to
   `N:\Projects\Arma 4\ArmaReforger.versions\<label>\` first — so previous versions
   are kept for comparison.
2. `.scripts/compare_versions_fast.py` diffs two trees:
   - `previous` (default): latest archive → current tree
   - `experimental`: current tree → `ArmaReforgerExperimental`
   - `--old PATH --new PATH`: any two trees
   Results: `.tmp/reforger-compare/version_comparison_results.json`
3. `/update-reforger [label] [experimental]` orchestrates the whole thing — detects a
   new build via the Steam appmanifest buildid, runs extraction, compares, runs
   `tools/compile-check.sh` against the new build, and writes
   `<label>-changes.md` into this directory.
